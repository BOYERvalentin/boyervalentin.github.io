# Modèle de portfolio — BTS SIO, épreuve E5

Ce dépôt est un **modèle**. Ne travaillez pas dedans : cliquez sur **Use this template**, puis **Create a new repository**.

Rendu du modèle : https://sebastienconfrere.github.io/portfolio-bts-sio-modele

## En quatre étapes

1. **Use this template** > *Create a new repository*.
2. Nommez votre dépôt **exactement** `votrepseudo.github.io` (votre pseudo GitHub, en minuscules) et laissez-le **Public**.
3. Onglet **Settings > Pages** : source *Deploy from a branch*, branche `main`, dossier `/ (root)`, puis **Save**.
4. Attendez 1 à 3 minutes, ouvrez `https://votrepseudo.github.io`, puis déposez l'adresse dans le devoir Teams.

## Comment modifier une page

1. Cliquez sur le fichier (`index.html` ou `situation-01.html`).
2. Cliquez le **crayon** en haut à droite du fichier.
3. Modifiez **uniquement le texte entre les chevrons**. `<h1>Titre de la situation</h1>` devient `<h1>Remplacement d'une carte mère</h1>` : on ne touche ni au `<h1>` ni au `</h1>`.
4. Bouton vert **Commit changes**, puis **Commit changes** dans la fenêtre qui s'ouvre.
5. Attendez 1 à 3 minutes et rechargez votre adresse.

Page cassée ? Onglet **History** du fichier, ouvrez la version précédente et restaurez-la. Rien n'est jamais perdu.

## Ajouter une situation

Ouvrez `situation-01.html`, bouton **Raw**, sélectionnez tout et copiez. Puis **Add file > Create new file**, nommez le fichier `situation-02.html`, collez, modifiez, commit. Ajoutez enfin la ligne correspondante dans la rubrique *Réalisations* de `index.html`, en copiant celle qui existe déjà.

## Ce que contient le modèle

- `index.html` — la page d'accueil et les cinq rubriques : Parcours, Compétences, Réalisations, Veille, Contact.
- `situation-01.html` — le modèle d'une situation professionnelle : contexte, problématique, démarche, outils, précautions, résultats, bilan personnel.

## Les règles à respecter

- L'adresse doit s'ouvrir **sans compte ni mot de passe**, et fonctionner jusqu'à la session d'examen 2028.
- Aucune donnée personnelle superflue : pas d'adresse postale, pas de numéro de téléphone.
- Aucune donnée d'entreprise identifiable : anonymisez (« une PME de 40 postes », « le site de Roanne »).
- On ne publie pas un brouillon : la version publiée est une version relue.
